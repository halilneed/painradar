# Channel notes (evidence-based, 2026)

Reference for the `launch` skill. Each rule carries the source it comes from so the plan
can cite it. Update this file as the market moves; a rule without a source gets removed.

## What the verified-revenue data says (trustmrr.com/stats, snapshot 2026-08)

- About two-thirds of Stripe-verified startups earn under $1k; roughly 1 % pass $1M.
  Distribution, not building, separates them.
- Revenue correlates with Domain Rating (r≈0.42) more than with founder X followers
  (r≈0.28) → invest in pages that earn links (comparisons, "alternative to", data posts),
  not in vanity follower counts.
- Fast-growing verified categories: Content Creation and Marketing (incl. AI-visibility /
  AEO tools), Analytics. Open-source-first products (social scheduler, LLM gateway) sit in
  the top 50 with verified MRR → OSS repo as top-of-funnel is a proven pattern.
- TrustMRR itself: ~200k monthly visitors browse verified startups; founders can list,
  show a verified MRR badge, post updates to the feed and join a category page. Listing is
  free distribution + trust. (trustmrr.com, /channels, /why-sell-on-trustmrr)

## Channel rules

**Reddit (primary for many indie products, highest intent).**
- One subreddit, reply-first presence for weeks before any product mention; answer with
  substance; the ratio is ~80 % help / ≤ 20 % mention, and only when relevant.
- Cross-posting a launch to five subreddits ≈ five bans (buildinpublic.so, 2026-05).
- Reddit threads rank on Google → an answer that truly solves a complaint keeps paying.
- Platform risk: data-API licences are expensive and enforcement tightened in 2025–2026
  (GummySearch shut down; May 2026 lockout) → participate as a human, never build the
  funnel on scraping.

**Hacker News (developer products, trust).**
- Show HN: plain title, what it does, why you built it, honest limits; no marketing
  voice; respond to every substantive comment for 24 h.
- Ask HN comments and "What are you working on?" threads are where distribution pain
  shows up ("still figuring out the target audience and how to advertise", 2026-07).
- US working hours, Tue–Thu tend to outperform (shippedsolo.com, 2026-07).

**Product Hunt (supporting, not primary).**
- Role shrank by 2026; traffic is curiosity-driven, not buyer-intent; use as a
  supporting burst once positioning is proven (buildinpublic.so; prems.ai).

**SEO (compounding; the only channel that pays back for years).**
- "X alternative", "X vs Y", "why does X …" and how-to pages built from the complaint
  phrasing; comparison pages earn links → Domain Rating → revenue correlation above.
- AI Overviews / zero-click cut informational clicks by roughly a third (Ahrefs) → write
  pages that *must* be clicked: tools, data, comparisons, templates; add an `llms.txt`
  and FAQ schema so AI answers can cite you.

**Communities (Discord/Slack/Indie Hackers).**
- High-intent, moderation heavy; 1–2 h/week for weeks before any share; a useful post in
  a 5k-member server can send hundreds of visits (shippedsolo.com).

**Cold outreach / operator DMs.**
- Highest conversion per hour for B2B-ish indie products; personal, referencing a thread
  or public complaint; never templated spam (buildinpublic.so).

**Build in public with verified numbers.**
- Post progress with TrustMRR-verified MRR rather than screenshots; revenue outpaced
  followers in most verified cases, so the number is the story, not the audience size.

## Sequencing template (first 90 days)

1. Days 1–30: pick one primary channel; publish 2 comparison pages; answer 15 real
   threads from the radar; list on TrustMRR; collect 10 conversations.
2. Days 31–60: Show HN or main community launch; 2 more pages; first 3 paying users;
   weekly build-in-public update with verified numbers.
3. Days 61–90: double down on what converted, cut the rest; add one supporting channel;
   measure trial→paid and page impressions weekly; decide kill/continue.
